# Assets Directory

This directory contains images and preview assets for the repository.

## Expected Files

- `banner.webp` — Repository banner image (1200x630)
- `thumbnail.webp` — Thumbnail image (400x300)
- `preview/` — Preview images for individual content items

## Notes

- Images should be optimized WebP format
- Banner is used on the main platform landing page
- Thumbnail is used in repository cards and listings
